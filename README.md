# PBell Master Lab

Cowboy Beatz prompt lab for the PBell custom Suno model.

This is a static app. It builds locked raw Atlanta trap instrumental prompts. Favorites, ratings, presets, custom triggers, and history stay in your browser (localStorage). Use Export JSON to back them up. There is no server and no account login.

## Use it

Open the GitHub Pages URL for this repository, or add it to your iPhone Home Screen from Safari (Share, then Add to Home Screen).

## Rules

The master formula stays locked. Only the sample trigger, BPM, and the optional uploaded-audio sentence change. Reset restores RuneScape-style MIDI, 150 BPM, and the uploaded audio sentence.
